De la intención al fotograma

Una configuración validada y versionada conecta todas las piezas.

  1. Perfil + borradorPantalla, cámara y voz con preferencias independientes.
  2. Capacidades + negociaciónMotor local y perfil exacto por receptor.
  3. Plan de aplicaciónRevisión, cambios en directo o reinicio, restauración.
  4. Captura → codificador → transporteColas acotadas, prioridad para voz y control.
  5. Reordenación → decoder → reloj A/VPlazos y reproducción según el perfil.
  6. Observación → adaptaciónFPS reales, colas, pérdidas y motivos de degradación.
