Cómo abrirlo en Windows

  1. Guarda el archivo EXE en una carpeta donde puedas escribir.
  2. Abre el archivo desde la carpeta donde lo guardaste. QuicNet conserva sus datos al actualizar.
  3. Comparte tu código de invitación o pega el de un contacto para conectar.

Cómo instalarlo en Android

  1. Guarda y abre el archivo APK desde Descargas.
  2. Si Android lo solicita, permite instalar aplicaciones desde el navegador o gestor de archivos que estés usando.
  3. Confirma la instalación y abre QuicNet. Si ya lo tienes, instala la actualización sobre la aplicación existente para conservar tus datos.

Linux: permite ejecutar el archivo después de guardarlo. Necesita GTK 3 y WebKitGTK 4.1 para la ventana; también puede abrirse en tu navegador.
