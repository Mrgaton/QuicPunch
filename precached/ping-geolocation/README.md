# Archivo del experimento de geolocalización por latencia

Archivado el 6 de noviembre de 2026 a petición del usuario. Esta carpeta conserva código y datos de referencia; **no es una caché desechable**. No forma parte de la solución, la aplicación, las pruebas activas ni los paquetes de publicación.

Se conserva la biblioteca experimental completa, la aplicación de laboratorio, NetLocate, los sondeos ICMP/TCP, traceroute, calibraciones, mapas, catálogos de referencias, herramientas, informes y las antiguas integraciones de QuicNet y sus pruebas.

Los archivos mantienen su estructura relativa para facilitar una recuperación futura. Las integraciones conservadas son históricas: no son un complemento instalable ni se ejecutan desde la aplicación. Las rutas de herramientas y dependencias externas pueden requerir adaptación para ejecutar el experimento de forma independiente.

QuicNet solo utiliza la biblioteca activa `QuicNet.Geolocation` para consultas locales a los catálogos comprimidos de IPTrust, ASN y localidades. No hay referencias desde el código activo a este archivo.

No se han movido ni eliminado historiales de análisis existentes en la carpeta de configuración del usuario. La aplicación ya no los lee.
