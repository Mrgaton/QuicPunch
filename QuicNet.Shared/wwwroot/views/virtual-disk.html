Disco virtual

Envía archivos, recibe en tu bandeja y comparte carpetas entre el móvil y el ordenador.

Enviar y recibir

Elige un contacto autorizado. Tú decides qué puede ver y durante cuánto tiempo.

Compartir archivos crea una carpeta de envío de solo lectura durante 24 horas. Al activar recepción, este contacto podrá enviar archivos a su propia bandeja; no podrá borrar. En el otro equipo, pulsa Conectar y abre la carpeta compartida.

Selecciona un equipo para ver sus carpetas compartidas.

    Compartir esta ubicación

    El administrador puede explorar y seleccionar cualquier disco o carpeta accesible para Quicknet. Un amigo solo ve lo que le compartes.

    Desde otro dispositivo, compartir crea acceso para tu propia identidad. El propietario puede revocarlo en cualquier momento.

    Actividad de este dispositivo

    Unidad de red local

    Esta dirección privada solo funciona en este dispositivo mientras QuicNet esté abierto. En Windows se necesita el servicio WebClient. Si una aplicación no puede guardar en la unidad, puedes subir el archivo desde esta vista.
