Decodificación en este dispositivo

El modo real se confirma con los fotogramas recibidos. «Solo hardware» muestra un error si el dispositivo no puede decodificar el perfil.

Latencia de recepción

0 ms presenta lo recibido inmediatamente. Un buffer mayor programa la presentación usando las marcas de tiempo del vídeo. La cola tiene un límite adicional de 16 MiB; al saturarse espera un fotograma clave para recuperarse.

Diagnóstico del motor seleccionado

Windows prueba los codificadores con vídeo sintético. Android consulta los componentes MediaCodec y valida su apertura al compartir. La recepción se comprueba decodificando muestras reales a 640×360. Estas pruebas no garantizan el rendimiento del perfil final.
