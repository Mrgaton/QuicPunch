Publicar una actualización

Las versiones se distribuyen desde cdn.gato.ovh/QuicNet. El EXE AOT y la APK comparten una versión y un número de compilación creciente.

Para ti o para un agente

  1. Abre el repositorio y lee doc/deployment/auto-updates.md. Conserva las claves de firma existentes.
  2. Elige una versión y un Build mayor que los publicados en Estable y Beta. Ejecuta las pruebas.
  3. Prepara una prueba en el canal Beta con PowerShell 7:
    ./scripts/publish-updates.ps1 -Version 1.1.11 -Build 13 -Channel beta -LocalOnly
  4. Revisa la compilación y publica los mismos archivos:
    ./scripts/publish-updates.ps1 -Version 1.1.11 -Build 13 -Channel beta -SkipBuild -CdnRoot 'Z:\CDN\QuicNet'
  5. Verifica por HTTPS el manifiesto y prueba una actualización en PC y Android.

El script incorpora las bibliotecas al EXE AOT, firma la APK, calcula los hashes, firma el manifiesto y sube primero los archivos. Solo al terminar activa la nueva versión.

No copies claves privadas al servidor. No sobrescribas archivos de una versión publicada: incrementa Build.

Beta publica latest-beta.json y conserva intacto latest.json, el canal Estable. Para publicar una versión definitiva, recompila con un Build superior y -Channel stable.

Qué hace cada dispositivo

Comprueba al abrir y cada 15 minutos; si el CDN falla, reintenta cada minuto. Puedes desactivar la instalación automática en Ajustes.

En Ajustes → Actualizaciones puedes elegir Estable o Beta. Las instalaciones nuevas de pruebas seleccionan Beta por defecto. La elección se conserva al actualizar; volver a Estable espera una compilación superior y conserva tus datos.

Estable recibe solo releases. Beta recibe tanto pruebas como releases y elige la compilación más reciente. Instalar una estable no te saca de Beta: seguirás recibiendo las próximas pruebas. La descarga e instalación automáticas respetan la opción de cada dispositivo.

En PC sustituye el EXE y reinicia; conserva una copia anterior y la recupera si la nueva versión no arranca. El EXE debe estar en una carpeta donde puedas escribir.

En Android descarga la APK y abre el instalador del sistema. Debes permitir esa fuente y confirmar. Debe mantenerse el certificado de firma de la APK instalada para conservar tus datos.

Una instalación anterior a este sistema requiere instalar manualmente la primera versión que lo incorpora.
